# DevOps & Cloud Engineer Portfolio

Welcome to my personal DevOps & Cloud Engineering Portfolio hosted on an **AWS EC2 instance** using an automated **CI/CD pipeline**.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Tailwind CSS), Vanilla JavaScript
- **Cloud Infrastructure:** AWS EC2, Security Groups, Elastic IP
- **Web Server:** Nginx
- **CI/CD Pipeline:** GitHub Actions
